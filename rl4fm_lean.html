Lean と強化学習

和地 瞭良 · 2026年11月25日

『基盤モデルのための強化学習』の 5.2.2 節でも Lean について解説したのですが、本ブログでも少し補足します。 理由はシンプルで、リーマン予想やらナビエ・ストークス方程式やらで Lean がものすごく注目されている一方で、本書での扱いはそこまで大きくありません。 お恥ずかしながら、本書を執筆していた 2026 年 6 月時点ではヤコビ予想の反例も見つかっておらず、見開き 1 ページくらい割けば十分だと考えていました・・・

Lean と強化学習を組み合わせるアプローチが大きく注目されたのは、2024 年の国際数学オリンピックにおいて、Google DeepMind の AlphaProof 銀メダル相当の成績を収めたときです。 例のごとく、OpenAI や Anthropic の学習方法は公開されていないのですが、Google Deepmind や DeepSeek は論文を公開しているので、Lean がどのように用いられているのか、コアとなるアイデアについて本ブログでは解説します。

  1. Hubert et al. Olympiad-level formal mathematical reasoning with reinforcement learning. Nature 651, 607–613
  2. Xin et al. (2024). DeepSeek-Prover-V1.5: Harnessing Proof Assistant Feedback for Reinforcement Learning and Monte-Carlo Tree Search.
  3. Ren et al. (2025). DeepSeek-Prover-V2: Advancing Formal Mathematical Reasoning via Reinforcement Learning for Subgoal Decomposition.
なお、私も Lean 自体はまだ勉強中なので、もし間違えていたら優しく教えていただけると幸いです。

Lean での証明

DeepSeek-Prover-V1.5 の論文 [2] に記載されている AIME（国際数学オリンピックのアメリカ予選）の問題を用いて、Lean でどのように証明がなされるのかを解説します。

\(0 < x < \pi\) を満たす全ての実数 \(x \in \mathbb{R}\) について、次の不等式を示せ。

\[\frac{9x^2\sin^2 x + 4}{x\sin x} \ge 12\]

この証明自体は全然難しくありません。\(t=x\sin x\) と置くと、\(0 < x < \pi\) から \(t>0\) です。 したがって、示したい不等式は \(9t^2-12t+4\ge 0\) になります。 左辺は \(9t^2-12t+4 = (3t-2)^2\) ですので、題意が示されています。

この証明は、Lean では以下のように記述することができます。 ブラウザ上で Lean が使える Lean Web で、次のブロック全体を貼り付けてください。 Lean Web 上で一行ずつ消したり足したりしながら挙動を見ると、分かりやすいし面白いと思います。 

import Mathlib

theorem aime_1983_p9 (x : ℝ) (h : 0 < x ∧ x < Real.pi) :
    12 ≤ (9 * (x ^ 2 * Real.sin x ^ 2) + 4) / (x * Real.sin x) := by
  have hpos : 0 < x * Real.sin x := by
    apply mul_pos
    · exact h.1
    · exact Real.sin_pos_of_pos_of_lt_pi h.1 h.2
  rw [le_div_iff₀ hpos]
  nlinarith [sq_nonneg (3 * x * Real.sin x - 2)]

コードの先頭で読み込む Mathlib は、数学の定義や証明済みの定理、証明に使うツールを集めた Lean の数学ライブラリです。 これだけだと分からないと思うので、一行ずつ解説していきます。

1. 仮定とゴールの定義

import Mathlib

theorem aime_1983_p9 (x : ℝ) (h : 0 < x ∧ x < Real.pi) :
    12 ≤ (9 * (x ^ 2 * Real.sin x ^ 2) + 4) / (x * Real.sin x) := by
>(x : ℝ) は実数の変数宣言、h はh : 0 < x ∧ x < Real.piを「かつ」で結んだ仮定の名前です。 その後のコロンから := までが示したい命題、by から先が証明です。

この 3 行を Lean Web に入力すると、以下のような 3 行が tactic state（証明の状態）として出力されると思います。 まだ何も証明が進んでいないので面白くありませんが、上の2行には、いま使える変数 x : ℝ と仮定 h : 0 < x ∧ x < Real.pi が記述されています。 最後の行で ⊢ の右にある不等式が、これから示すべき命題、つまりゴールです。 

x : ℝ
h : 0 < x ∧ x < Real.pi
⊢ 12 ≤ (9 * (x ^ 2 * Real.sin x ^ 2) + 4) / (x * Real.sin x)

2. \(x \sin x > 0\) をまず示す

import Mathlib

theorem aime_1983_p9 (x : ℝ) (h : 0 < x ∧ x < Real.pi) :
    12 ≤ (9 * (x ^ 2 * Real.sin x ^ 2) + 4) / (x * Real.sin x) := by
  have hpos : 0 < x * Real.sin x := by

証明状態を操作する指示を tactic と呼びます。ここで使う have は、途中で使いたい命題に名前を付け、その証明を始める指示です。 内側の by に入った直後は、 

⊢ 0 < x * Real.sin x
がゴールです。ここで使えるのはもとの仮定 h だけで、hpos 自身はまだ使えません。このゴールを閉じて外側に戻ると、証明済みの事実として hpos が使えるようになります。

3. \(x \sin x > 0\) を二つのゴールに分ける

import Mathlib

theorem aime_1983_p9 (x : ℝ) (h : 0 < x ∧ x < Real.pi) :
    12 ≤ (9 * (x ^ 2 * Real.sin x ^ 2) + 4) / (x * Real.sin x) := by
  have hpos : 0 < x * Real.sin x := by
    apply mul_pos

mul_pos は、Mathlib に収録されている「正の数どうしの積は正」という定理です。上の例では、apply mul_pos は「この定理を使って \(x\sin x > 0\) を示す」という指示となります。このとき、\(x > 0\) と \(\sin x > 0\) が、Lean 上の新たなゴールとなります。

⊢ 0 < x
⊢ 0 < Real.sin x

4. \( 0 < x\) を示す

import Mathlib

theorem aime_1983_p9 (x : ℝ) (h : 0 < x ∧ x < Real.pi) :
    12 ≤ (9 * (x ^ 2 * Real.sin x ^ 2) + 4) / (x * Real.sin x) := by
  have hpos : 0 < x * Real.sin x := by
    apply mul_pos
    · exact h.1

· で 0 < x という一つ目のゴールに関して証明を試みます。h.1 は仮定 h の前半、つまり 0 < x という証拠です。exact にゴールと一致する証拠を渡すと、0 < x というゴールが閉じます。

⊢ 0 < Real.sin x

5. \(0 < x < \pi\) で \(\sin x > 0\) を示す

import Mathlib

theorem aime_1983_p9 (x : ℝ) (h : 0 < x ∧ x < Real.pi) :
    12 ≤ (9 * (x ^ 2 * Real.sin x ^ 2) + 4) / (x * Real.sin x) := by
  have hpos : 0 < x * Real.sin x := by
    apply mul_pos
    · exact h.1
    · exact Real.sin_pos_of_pos_of_lt_pi h.1 h.2

Real.sin_pos_of_pos_of_lt_pi は、Mathlib に収録されている「\(0 < x < \pi\) ならば \(\sin x > 0\)」という定理です。h.1 が \(0 < x\)、h.2 が \(x < \pi\) の証拠なので、この二つを定理に渡すと \(0 < \sin x\) の証明が得られます。これは二つ目のゴールそのものなので、exact で閉じられます。これで、hpos が使えるようになり、Lean 上の tactic state に hpos : 0 < x * Real.sin x が追加されました。

x : ℝ
h : 0 < x ∧ x < Real.pi
hpos : 0 < x * Real.sin x
⊢ 12 ≤ (9 * (x ^ 2 * Real.sin x ^ 2) + 4) / (x * Real.sin x)

6. 両辺に \(x \sin x\) をかける

import Mathlib

theorem aime_1983_p9 (x : ℝ) (h : 0 < x ∧ x < Real.pi) :
    12 ≤ (9 * (x ^ 2 * Real.sin x ^ 2) + 4) / (x * Real.sin x) := by
  have hpos : 0 < x * Real.sin x := by
    apply mul_pos
    · exact h.1
    · exact Real.sin_pos_of_pos_of_lt_pi h.1 h.2
  rw [le_div_iff₀ hpos]

rw はゴールを書き換える指示です。Mathlib の le_div_iff₀ に「\(0 < x < \pi\) において \(x \sin x > 0\) である」という証明済みの定理 hpos を渡すと、分母を払った同値な不等式に書き換えられます。

⊢ 12 * (x * Real.sin x) ≤ 9 * (x ^ 2 * Real.sin x ^ 2) + 4

7. 証明完了

import Mathlib

theorem aime_1983_p9 (x : ℝ) (h : 0 < x ∧ x < Real.pi) :
    12 ≤ (9 * (x ^ 2 * Real.sin x ^ 2) + 4) / (x * Real.sin x) := by
  have hpos : 0 < x * Real.sin x := by
    apply mul_pos
    · exact h.1
    · exact Real.sin_pos_of_pos_of_lt_pi h.1 h.2
  rw [le_div_iff₀ hpos]
  nlinarith [sq_nonneg (3 * x * Real.sin x - 2)]

Mathlib の sq_nonneg は、「平方式は非負」という定理です。ここでは、\((3x \sin x − 2)^2\) > 0」を用いていることになります。nlinarith が多項式を整理し、\(9 x ^ 2 \sin x ^ 2 - 12 x \sin x + 4 > 0\) を導きます。Lean Web でこの行の直後に No goals と出れば、証明は完了です。

No goals

環境としての Lean

AlphaProof や DeepSeek-Prover では Lean を強化学習の環境として用いています。Lean の tactic state（証明状態）が強化学習における状態であり、基盤モデル（方策）は「どのようなコードを出力するか」の行動を選択します。環境である Lean がこの行動を実行すると、新しいtactic state（証明状態）が得られます。have hpos の内側で \(x \sin x > 0\) を示すのを例に、状態・行動が何に対応しているかを説明します。
